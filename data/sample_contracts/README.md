# Sample contracts

These files are synthetic test fixtures for RedLiner. They are not legal advice
and should not be used as executable agreements.

All source fixtures include a price so the commercial utility engine has an
offered amount. The default target is 10% below the offer.

| File | Price | Expected result |
|---|---:|---|
| `sample_clean_saas_agreement.docx` | $120,000 | 0 redlines |
| `sample_medium_risk_saas_agreement.docx` | $120,000 | 3 findings |
| `sample_professional_services_agreement.docx` | $120,000 | 2 findings |
| `sample_data_processing_addendum.docx` | $120,000 | 6 findings, critical |
| `sample_unfavorable_saas_agreement.docx` | $120,000 | 7 findings |
| `sample_commonpaper_cloud_service_agreement.docx` | $150,000 | 0 redlines |
| `sample_acc_cooley_style_saas_agreement.docx` | $240,000 | 4 findings |
| `vendor_saas_agreement.docx` | $120,000 | Baseline vendor draft |
| `vendor_saas_agreement.pdf` | $120,000 | PDF parser fixture |

`vendor_saas_agreement_redlined.docx` is a generated redlined artifact, not a
source contract. It is excluded from the sample-mailer list.

## Attribution and sources

### Common Paper

`sample_commonpaper_cloud_service_agreement.docx` is a synthetic example
adapted from the **Common Paper Cloud Service Agreement**:

- Source: <https://commonpaper.com/standards/cloud-service-agreement/>
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Changes: condensed, restructured into RedLiner clause headings, and modified
  to include synthetic parties, pricing and test-specific terms.

Common Paper is not affiliated with or endorsing RedLiner.

### ACC/Cooley SaaS Agreement form

`sample_acc_cooley_style_saas_agreement.docx` is an original synthetic SaaS
agreement whose structure was inspired by the ACC/Cooley SaaS Agreement form.
No text from that form is reproduced. It is not affiliated with or endorsed by
the Association of Corporate Counsel or Cooley LLP.

### Other fixtures

The remaining DOCX/PDF fixtures are original synthetic content generated by
`scripts/generate_sample_contracts.py` for testing parsing, redlining, pricing,
HITL and email workflows.
